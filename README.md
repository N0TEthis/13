# 16.13.Текст.
Хранит строку переменной длины представляющую собой последовательность
предложений. Методы: добавить предложение, удалить предложение, вставить
предложение, количество (букв, слов, предложений), предложение под
заданным номером, самое длинное предложение, самое короткое предложение,
есть ли в тексте заданное предложение, равны ли два текста.

класс TEXT хранит строку из предложений , оканчивающихся на . ! ?
предлодения находятся по номеру , и через жто выполняются добавление , вставка , удаление и получение предлодения ..
буквы Б слова и предлодения считаются по символлам строки 
самое длинное и самое короткое предложения определяютс сравнением длин..
два текста равны , если все их предложения совпадают по порядку
